CARLITOS STRONG — INTERACTIVE 8-WEEK TRAINING TRACKER
====================================================

FILES
- index.html: The full program with illustrated exercises, sets, weights, reps, notes and history.
- manifest.webmanifest, sw.js, icon-192.png, icon-512.png: Installable iPhone web-app files.

ON A DESKTOP COMPUTER
1. Double-click index.html in a browser such as Chrome or Edge.
2. Choose a workout day. Pick a date. Enter sets, weights (lb), reps or drill times.
3. Tap/click Mark done next to each exercise, and Finish this workout at the bottom.
4. In Progress, export a JSON backup periodically. CSV export is for spreadsheets.

ON AN IPHONE (BEST METHOD: HOST AS A SECURE WEBSITE)
1. Create a GitHub account and a new repository (e.g. carlitos-training). GitHub Pages sites on free plans are generally published from public repositories. Do not upload personal logs or identifying personal details; the website files are program code only.
2. Upload ALL five app files to the TOP/ROOT of the repository (not inside a subfolder).
3. GitHub repository > Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
4. GitHub will show a website link (typically https://USERNAME.github.io/carlitos-training/).
5. Open that link in Safari on the iPhone, then Share > Add to Home Screen > enable Open as Web App (if available) > Add.
6. Open the new icon to make changes. Most of the app can be used offline after the first successful online load and installation.

KEY DATA LIMITATION
Data is stored only inside the browser/web app on THAT device. It does not automatically synchronize between iPhone and Windows. Export backup on one device, share the JSON file via iCloud Drive/AirDrop/email to the other, then Import backup there. Import REPLACES that device's existing data. Always export first if both devices contain updates. Back up regularly as browser storage may be erased. The iPhone Home Screen app may store data separately from regular Safari.

IPAD / IPHONE ATTACHMENT LIMITATION
Opening index.html directly in the Files app may show an inert preview and not run its JavaScript or save the tracker. The hosted HTTPS address is more dependable for editing and Add to Home Screen.

HEALTH/SAFETY
This is a starter training guide for a growing 11-year-old, not a medical program. Adult supervision and good form are essential. Use light/moderate loads, avoid training to failure or one-rep max attempts, and consult pediatrician/qualified youth coach if medical concerns arise. Avoid numeric weight-loss targets for a child without guidance. Adjust workload around basketball/volleyball practice.
